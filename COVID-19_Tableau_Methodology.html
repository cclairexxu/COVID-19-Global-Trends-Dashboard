COVID-19 Tableau Project Methodology

Data Preparation

  • Data source: Our World in Data COVID-19 dataset
  • Date range: January 1, 2020 – August 14, 2024
  • Removed aggregate locations (World, continents, income groups) by filtering rows where continent was not missing.
  • Spot-checked several countries (United States, India, Brazil, Iceland, Fiji, Luxembourg) for reporting gaps.

Calculated Fields

1. Case Fatality Rate (CFR)

Calculated Field

SUM([Total Deaths]) / SUM([Total Cases])

Purpose

Measures the proportion of reported COVID-19 cases that resulted in death.

Validation

  • Checked country-level CFR values.
  • Values were within expected low single-digit percentages.
  • No negative or extreme values were observed.

2. Vaccination Rate

Calculated Field

AVG([People Fully Vaccinated Per Hundred]) / 100

Purpose

Calculates the average reported percentage of fully vaccinated individuals and converts the value into a percentage format.

Validation

  • Checked country-level vaccination rates.
  • Values were within expected 0-100% range.

3. Vaccination Rate (Max 100%)

Calculated Field

IIF([Vaccination Rate] > 1, 1, [Vaccination Rate])

Purpose

Ensures vaccination rates remain within the valid 0–100% range. If a value exceeds 100% due to aggregation issues, it is adjusted to 100% to prevent unrealistic percentages in visualizations.

Validation

  • Confirmed that vaccination rates remained between 0% and 100%.
  • Checked that no invalid percentage values appeared in visualizations.

Trend Analysis and Parameters

1. 7-Day Rolling Average

Calculated Field

WINDOW_AVG(SUM([new_cases]), -6, 0)

Purpose

Calculates a 7-day rolling average of daily new COVID-19 cases by averaging the current day and the previous six days. In the formula, -6 represents the six previous days included in the calculation, and 0 represents the current day.

Validation - Created a line chart using daily dates and a selected country. - Compared the 7-day rolling average with daily new cases and confirmed that the trend was smoother. - Checked that the calculation used a 7-day window across dates.

2. Date Range Filter

Method

Used Tableau’s built-in date range filter to allow selection of the time period displayed in visualizations.

Steps

  1. Drag date into filter in worksheet.
  2. Select Range of Dates.
  3. Adjust minimum and maximum dates.

Alternative

  1. Create parameter: Start Date
  2. Data Type: Date
  3. Set current value: 8/14/2024 as example
  4. Create calculated field:

  • Name: Date Range Filter

  • Calculated Field: [date] >= [Start Date] AND [date] <= [End Date]

  • Meaning:

    • [date] >= [Start Date]: Keep dates after or equal to the selected start date.

    • [date] <= [End Date]: Keep dates before or equal to the selected end date.

  1. Drag to filter and select TRUE.
  2. Right-click Start Date and select Show Parameter, repeat for End Date.

Purpose

Allows users to focus on specific periods of the COVID-19 timeline and adjust the range of dates shown in trend analysis.

Validation

  • Confirmed that changing the date range updated the visualization correctly.
  • Verified that only dates within the selected range were displayed.

3. Country Selector Filter

Parameter

Country Selector

Data Type

String

Calculated Field

[location] = [Country Selector]

Purpose

Allows users to select a single country and update country-specific trend visualizations.

Validation

  • Confirmed that changing the selected country updates the visualization.
  • Verified that only the selected country’s data is displayed.

4. Metric Selector Parameter

Parameter

Metric Selector

Data Type

String

Calculated Field

CASE [Metric Selector]
WHEN "Cases" THEN SUM([New Cases])
WHEN "Deaths" THEN SUM([New Deaths])
WHEN "Vaccination Rate" THEN [Vaccination Rate (Max 100%)]
END

Purpose

Allows users to switch between different COVID-19 metrics within the same visualization.

Validation

  • Confirmed that changing the parameter updates the selected metric.
  • Verified that each metric displays the expected measure (new cases, new deaths, and vaccination rate).

Global Choloropleth Map

Purpose

Created a world map visualization to compare COVID-19 impact across countries using population-adjusted case counts.

Map Setup

  • Created a geographic map using the location field.
  • Verified that Tableau recognized country names and generated country-level map regions.
  • Applied toal_cases_per_million as the color metric to compare COVID-19 impact while accounting for differences in population size.

Aggregation Choice

  • Used MAX(total_cases_per_million) instead of SUM(total_cases_per_million).
  • Since each country has multiple records over time, using SUM would incorrectly add the same cumulative measure across different dates.
  • Used MAX to select the highest cumulative value for each country.

Filtering

  • Applied a continent filter to remove aggregate records such as World, regions, and income groups.
  • Added a date filter to allow selection of the reporting date or range of dates.

Validation

  • Confirmed that countries were mapped correctly and no major geographic errors were identified.
  • Verified that map colors displayed reasonable differences between countries.

Development Note

  • Built upon the choropleth map tested during the validation phase.
  • The test visualization was refined by adding the final metric, filters, and formatting adjustments.

Top 10 Country Comparisons

Purpose

Created bar charts to compare countries based on total COVID-19 cases, case fatality rate (CFR), and vaccination rate.

1. Top 10 Countries by Total Cases

  • Created a horizontal bar chart ranking countries by cumulative COVID-19 cases.
  • Used MAX(total_cases) because the dataset contains multiple records per country over time, and summing cumulative values across dates would incorrectly inflate totals.
  • Applied a Top 10 filter and removed aggregate records (such as World and regions) using the continent filter.
  • Sorted countries from highest to lowest total cases.

2. Top 10 Countries by Case Fatality Rate (CFR)

  • Created a horizontal bar chart ranking countries by CFR.
  • Applied a Top 10 filter based on CFR values and sorted countries from highest to lowest.
  • Kept the calculated field as an aggregated calculation (AGG(Case Fatality Rate (CFR))) since the formula already calculates the ratio of total deaths to total cases.
  • Verified that CFR values were within reasonable ranges.
  • Noted that countries with fewer reported cases may have higher variation in CFR because small changes in deaths can greatly affect the percentage.

3. Top 10 Countries by Vaccination Rate

  • Created a horizontal bar chart ranking countires by vaccination rate.
  • Used MAX(Vaccination Rate (Max 100%)) because vaccination rates increase over time, and the maximum value represents the highest/latest reported vaccination coverage for each country.
  • Applied a Top 10 filter and verified that vaccination rates remained between 0% and 100%.

Formatting

  • Applied consistent formatting across all three bar charts.
  • Standardized chart titles using the format “Top 10 Countries by [Metric].”
  • Simplified tooltips to display only the country name and corresponding metric value.
  • Ensured charts were sorted in descending order for easier comparison.

Validation

  • Confirmed that each chart displayed the correct Top 10 countries based on the selected metric.

  • Verified that cumulative measures (total cases and vaccination rate) were not incorrectly summed across dates.

  • Checked that aggregate records such as World and regional groups were removed from the rankings.

  • Verified that CFR values were displayed as percentages and remained within reasonable ranges.

  • Confirmed that vaccination rates remained between 0% and 100%.

  • Checked that sorting and filtering updated the charts correctly.

Formula

IF [gdp_per_capita] < 1136 THEN "Low income"

ELSEIF [gdp_per_capita] < 4466 THEN "Lower-middle income"

ELSEIF [gdp_per_capita] < 13845 THEN "Upper-middle income"

ELSE "High income"

END

Formula

Population density: Population Density = Population / Land Area
