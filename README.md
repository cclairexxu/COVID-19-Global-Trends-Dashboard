#  COVID-19 Global Trends Dashboard

## Description
Interactive Tableau dashboard analyzing global COVID-19 trends, vaccination coverage, and case fatality rates using Our World in Data COVID-19 data. The project explores geographic patterns, country-level trends, and relationships between vaccination rates and COVID-19 outcomes through interactive visualizations.

## Files
- [COVID-19_Tableau_Methodology.qmd](https://github.com/cclairexxu/covid19-global-trends-dashboard/blob/main/COVID-19_Tableau_Methodology.qmd) – Quarto source file documenting the dashboard methodology, including project purpose, visualization setup, formulas, validation steps, and analysis workflow.
